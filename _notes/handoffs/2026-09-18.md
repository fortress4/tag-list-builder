# Project Handoff — 2026-09-18

## Current state

- The tag-list builder is at version `0.2.0` in `version.json`, `package.json`, and the distributable JavaScript header.
- There were no pending tracked implementation changes before creating this handoff; this handoff file is the new untracked artifact.
- `index.cfm` remains the CFML-rendered example layout; `index.html` is the standalone HTML example. CFML is optional for consumers of the tag-list-builder browser code.
- The developer static-generation utility is not part of the Git repository or production library. Its generated output must preserve relative local asset URLs.

## Completed remediation

- Context-safe ColdFusion output encoding with `EncodeForHTML` and `EncodeForHTMLAttribute`.
- Safe DOM text rendering for tag values, including XSS regression coverage.
- JSON array storage by default, with one-time legacy comma-value migration.
- Explicit deprecated comma mode for server-side consumers that still need it.
- Case normalization before duplicate checking, with `normalizeStoredCase=false` by default.
- Readonly UI enforcement for adding, removing, and sorting.
- Generic typeahead initialization compatible with jQuery 4.
- Updated pinned demo dependencies: jQuery 4.0.0, Bootstrap 5.3.8, Bootbox 6.0.4, HTML5 Sortable 0.14.0, and jQuery Typeahead 2.11.1.
- Source/distribution parity check through `build.ps1 -Check`.
- Browser and CFML smoke tests under `tests/`.
- `package.json` peer dependency metadata and `version.json` release metadata.

## Verification

- `build.ps1 -Check` passes for the JavaScript and CSS distribution files.
- JavaScript syntax checks pass for source and distribution files.
- Chromium browser smoke test passed JSON migration, safe rendering, duplicate handling, sorting, readonly behavior, comma mode, invalid JSON rejection, and typeahead initialization.
- Lucee 5.4.8.2 served `index.cfm` successfully.
- CFML hostile-input smoke test returned `passed: true` with no executable elements.
- Static generation was verified with zero localhost URLs in the resulting `index.html` and relative local asset paths.
